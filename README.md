# Hello PHP Project

## Kako pokrenuti PHP skriptu

1. **Instalirajte PHP** ako već nemate. Možete preuzeti sa [https://www.php.net/downloads](https://www.php.net/downloads)

2. **Klonirajte repozitorijum**:
   ```bash
   git clone https://github.com/Sneza122/php-hello-world-projekat.git
3. **Udjite u direktorijum projekta**:
   cd php-hello-world-projekatt
4. **Pokrenite php skriptu**:
   php hello.php
5. **Očekivani ispis na terminalu**:
   Hello World (again)
